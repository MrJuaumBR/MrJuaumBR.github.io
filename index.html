NINTENDO 3DS HOMEBREW · DARK FANTASY ROGUELITE

Abyssal Eclipse 3DS

A 2D pixel-art arena-survivor roguelite built natively for the original Nintendo 3DS. Written in C++17 with devkitARM, libctru, citro3d, and citro2d. Status: v0.1 release.

Gameplay

You control a lone knight in a looping nightmare. Weapons attack automatically; move, dodge, collect experience, spend stat points, and build a spell loadout through timed waves and boss fights. There are 147 spells across six elements, 25 enemy types, and five seasons (Forest, Desert, Snow, Mountain, Eclipse) with 15 campaign levels. Clearing all 15 unlocks the All‑Seasons Map, an 800×600 arena that mixes enemies from every season.

Content and progression

23 achievements cover season clears, lifetime kill milestones, catalog discovery, spell‑use challenges, play‑time milestones, and cosmetic unlocks. Nine weapons are available, with the Machine Gun gated behind full campaign completion. Unused level‑up points can be banked for later in a run.

Presentation

Sprites, bitmap text, sound effects, and music are generated procedurally. A 256×256 RGBA8 texture atlas is built in RAM at startup, so the game needs no external runtime art files. Full English and Brazilian Portuguese localization.

Technical

Fixed gameplay pools and no gameplay heap allocation for old‑3DS stability, an optional 30 FPS battery‑saving mode, and a save loader that migrates legacy v1–v4 files to the current v5 format.

GITHUB PROJECT · PROCEDURAL GENERATION

DungeonGenerator

A configurable Python generator for seeded, multi-floor dungeon layouts, with both reusable generation code and a graphical app.

How the layout is built

Rooms are placed with Binary Space Partitioning (BSP), then a graph/BFS connection pass links the rooms and floors.
